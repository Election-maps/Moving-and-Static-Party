# 📍 శ్రీకాకుళం జిల్లా మూవింగ్ & స్టాటిక్ పార్టీ డ్యూటీల లైవ్ మ్యాప్ & ట్రాకర్

**శ్రీకాకుళం జిల్లాలోని 34 పోలీస్ స్టేషన్ల పరిధిలోని "మూవింగ్ పార్టీలు" (Moving Parties) మరియు "స్టాటిక్ పాయింట్లు" (Static Points) డ్యూటీ ఇన్-ఛార్జుల లొకేషన్లను కంట్రోల్ రూమ్‌లో రియల్-టైమ్‌లో పర్యవేక్షించేందుకు రూపొందించబడిన ప్రత్యేక అప్లికేషన్.**

## 🌟 ముఖ్య ఫీచర్లు (Key Features)

1. **పాయింట్ వైజ్ కేటగిరీలు (Point-wise Categories):**
   - 🚔 **Moving Parties (మూవింగ్ పార్టీలు):** 2W / 4W వాహనాలతో తిరిగే మొబైల్ పెట్రోలింగ్ పార్టీల లైవ్ కదలికలు, వేగం.
   - 📍 **Static Points (స్టాటిక్ పాయింట్లు):** ఫిక్స్‌డ్ చెక్‌పోస్టులు, ముఖ్య జంక్షన్లు, స్టాటిక్ పాయింట్ల వద్ద ఉండే సిబ్బంది డ్యూటీ లొకేషన్లు.
   - 🏛️ **34 పోలీస్ స్టేషన్ల వారీగా ఫిల్టర్:** జిల్లాలోని అన్ని పోలీస్ స్టేషన్ల డ్యూటీ వివరాలు క్షణాల్లో ఫిల్టర్ చేసుకోవచ్చు.

2. **ఎక్సెల్ డేటా ఆధారం (Excel-Powered):**
   - మీ వద్ద ఉన్న `Moving Partis and Static Points.xlsx` ఫైల్ ఆధారంగా ఈ సిస్టమ్ రూపొందించబడింది.
   - ఎక్సెల్‌లో ఏవైనా మార్పులు చేసినా వెంటనే `powershell -File build_dataset.ps1` రన్ చేస్తే చాలు; డేటా ఆటోమేటిక్‌గా అప్‌డేట్ అవుతుంది.

3. **బ్రౌజర్ రీఫ్రెష్ చేసినా లొకేషన్లు పోవు (Persistence):**
   - కంట్రోల్ రూమ్ బ్రౌజర్‌లో లోకల్ స్టోరేజ్ (`localStorage`) మరియు MQTT Retained Messages ద్వారా రీఫ్రెష్ చేసినా లైవ్ ఆఫీసర్లు మ్యాప్‌పై అలాగే ఉంటారు.
